🃏 Blackjack Casino (Python)

A console-based Blackjack Casino game built with Python using Object-Oriented Programming (OOP). The game simulates a real Blackjack experience with betting, wallet management, dealer AI, and an interactive menu system.

---

🎮 Features

- 🃏 Standard 52-card deck
- 🔀 Random deck shuffling before every round
- 👤 Player vs Dealer gameplay
- 💰 Betting system with wallet management
- 🚫 Prevents players from betting more than their available balance
- 🏦 Wallet reset option
- 👀 View wallet balance
- 📖 Help/Rules menu
- 🎯 Natural Blackjack detection
- 🤝 Push (tie) handling
- 💥 Player and dealer bust detection
- 🧠 Dealer automatically draws until reaching at least 17
- 📊 Displays winnings, losses, and updated wallet balance after every round
- ✅ Robust input validation for menu selections, bets, and player choices

🎲 Game Rules

- The objective is to get as close to 21 as possible without going over.
- Number cards are worth their face value.
- Face cards (Jack, Queen, King) are worth 10.
- An Ace is worth either 1 or 11 depending on which benefits the hand.
- The dealer must draw until reaching at least 17.
- A natural Blackjack is an Ace and a 10-value card as the initial two cards.
